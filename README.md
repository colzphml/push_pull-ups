# 💪 Push·Pull — отжимания и подтягивания с нуля

Персональная программа по методике Greasing the Groove: лёгкие подходы вне отказа,
разнесённые по дню. Недели карточками, прогресс в SQLite, генерация через скилл.

## Как пользоваться
- Сгенерировать неделю: `/make-week`
- Отмечать выполнение — прямо на странице недели, кружком на карточке
- Дать обратную связь: «вис стал 30 сек», «плечо ноет», «во вторник пропустил»
- Посмотреть прогресс: «покажи прогресс»

## Отметки выполнения

На карточке есть кружок: тап — сделал, ещё тап — не вышло, ещё — снять отметку.
После отметки появляется «✎ уточнить»: сколько реально вышло, ощущения, заметка.
В шапке недели — попадаемость по дням и счётчик холодных финишей.

Отметка сохраняется мгновенно в браузере (работает офлайн) и через пару минут
уезжает в этот же репозиторий файлом `history/log/YYYY-MM-DD.json`. Оттуда её
читает `/make-week` и заливает факт в `exercise_log`. Никаких внешних сервисов:
хранилище — сам git.

**Панель в шапке** говорит состояние словами, кнопка появляется только когда
от тебя что-то нужно:

| Что видно | Что значит | Что делать |
|---|---|---|
| 🟢 Всё отправлено | отметки уже в репозитории | ничего |
| 🟡 Отправляю… | запрос летит | подождать |
| 🟡 Не отправлено: N · «Отправить» | ждут дебаунса (2 мин) или сорвалась отправка | можно нажать, можно не трогать |
| 🔴 Нужен токен · «Ввести» | токена на этом устройстве нет | ввести токен |
| 🔴 текст ошибки · «Повторить» | GitHub отказал, причина написана | по ситуации |

**Токен.** Чтобы отметки уезжали, нужен fine-grained токен GitHub с правом
`Contents: Read and write` **только** на этот репозиторий. Вводится один раз
на каждом устройстве, хранится в `localStorage`, в репозиторий не попадает.
Поменять или удалить — «⚙» в правом углу панели. Стирается токен сам только
при 401 (GitHub прямо сказал «негоден»); при лимите запросов и нехватке прав
он сохраняется, чтобы не гонять по кругу «ввожу заново — снова не работает».

## Структура
```
push_pull-ups/
├── index.html              # витрина: список недель
├── weeks/2026/week_*.html  # недели (Дни/Прогрессия/Техника)
├── assets/tracker*.js      # трекер отметок (ядро, разбор, хранилище, GitHub, интерфейс)
├── tests/*.test.js         # тесты чистой логики (node --test, без зависимостей)
├── plan/progression.md     # мастер-план прогрессии
├── plan/cold.md            # мастер-план закаливания
├── equipment.md            # турник, резинки
├── profile.json            # 🔒 состояние (в .gitignore)
├── history/training.db     # SQLite: недели, лог, прогресс, правила
├── history/log/*.json      # факт выполнения — пишет трекер с телефона
└── .claude/skills/make-week/SKILL.md
```

## Разработка
```bash
node --test tests/*.test.js   # маска обязательна: `node --test tests/` в Node 26 не работает
```
Сборки нет — ванильные ES-модули, ни одной npm-зависимости.
Дизайн и план трекера: `docs/superpowers/`.
